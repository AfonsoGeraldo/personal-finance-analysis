# Personal Finance Analysis 💰

Personal data analysis project, focused on consolidating pandas skills — time series, aggregations, and visualization — using synthetic personal finance data.

## Goal
Practice pandas in depth (dates, resample, advanced groupby, rolling averages, pivot tables), using an artificially generated but realistically patterned dataset.

## Project structure
- `data/` — synthetic generated data
- `notebooks/` — exploratory analysis
- `src/` — reusable code (data generation, analysis functions)
- `requirements.txt` — project dependencies

## How to run
1. Create virtual environment: `python -m venv venv`
2. Activate: `venv\Scripts\activate` (Windows)
3. Install dependencies: `pip install -r requirements.txt`
